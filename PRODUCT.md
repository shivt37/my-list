# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Existing codebase: Cloudflare Worker (plain JS modules, no framework), single-file inline HTML/CSS/JS page generated by `src/configure.js`. Deployed via Wrangler; data files published to GitHub Pages; list regeneration runs on GitHub Actions (headless Chromium).

## Users

Single owner-admin (the developer). Power user, comfortable with URLs, JSON configs, GitHub Actions. Uses /configure on desktop primarily, occasionally on phone. No other accounts exist; there is no auth layer beyond obscurity.

## Product Purpose

MDBList Scraper is a Stremio/Nuvio catalog addon backend. The /configure page is its control panel: manage scraped MDBList lists, fixed MDBList official lists, fixed Simkl Arriving-Today lists, and TMDB Discover lists. Saving persists config to Cloudflare KV and dispatches GitHub Actions workflows that regenerate catalog JSON files served from GitHub Pages. Success = owner can add/tune/remove catalogs quickly and see what will regenerate.

## Positioning

Personal, self-hosted scraper-to-Stremio pipeline: unlike public addon configurators, it exposes raw scraping controls (page counts, rating tiers, AND/OR filter dimensions, live previews) directly to one expert user.

## Operating Context

- Local dev: `wrangler dev` on http://127.0.0.1:8787 (no GH_TOKEN → save is rejected with infra error; expected).
- Production: Cloudflare Worker + KV (`STORE`) + GitHub Actions dispatch (GH_TOKEN secret).
- Regeneration latency: minutes per scraped list (headless Chromium); seconds for TMDB/Simkl API fetches.
- Catalogs consumed by Stremio/Nuvio clients reading static JSON from GitHub Pages.

## Capabilities and Constraints

- Four module tabs: MDBList Scraper, MDBList Official List (fixed ×3), Simkl List (fixed ×2, rating-tier filters), TMDB List (discover builder: genres/keywords/companies/collections/release types, AND/OR combine modes, live preview).
- Save is global (all four modules in one POST /save-config); hash-compare dispatches only changed lists.
- Refresh actions trigger immediate GH Actions runs (all-lists or per-list).
- Accent colour is client-side only (localStorage), 12 presets.
- No server-side validation ofmdblist URLs beyond path shape; duplicate-name guards client-side.

## Product Principles

1. Density over ceremony: one expert user; show controls, not hand-holding.
2. Honest state: always make clear what saving will regenerate and what a refresh costs.
3. Dark-first precision: layered surfaces on #050508, restrained accent use.
4. Keyboard-respectful: AA contrast, visible focus, Escape/focus-trap correctness even though users are few.
